# Legacy Milestone Scripts (Archive)

> [!WARNING]
> **DO NOT EXECUTE ANY SCRIPTS IN THIS DIRECTORY.**
> These files (`apply_m1.sh`, `apply_m3.sh`, etc.) are early development snapshot patchers from the initial bootstrap phases of the CreatorCanvas project.
> Running any of these scripts will overwrite modern codebase files with obsolete bootstrap prototypes.

This directory is preserved solely for historical audit and repository evolution tracking.
All modern builds, tests, packaging, and CI/CD pipelines use CMake (`CMakePresets.json`), `packaging/linux/build_deb.sh`, `packaging/windows/build_portable.ps1`, and GitHub Actions workflows.
